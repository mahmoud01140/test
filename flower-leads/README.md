# نظام استخراج وتجميع محلات الزهور في مصر (Flower Leads Egypt) 🌸

نظام متكامل مبني باستخدام **JavaScript / Node.js**، يقوم بالبحث عن محلات بيع الزهور والورد في جميع المحافظات المصرية الـ 27، وجمع بياناتها المتاحة قانونياً، وفلترتها لمنع التكرار، وتخزينها في ملف JSON منظم مع إنشاء رسالة واتساب تسويقية مخصصة لكل محل لعرض خدمات تصميم المواقع الإلكترونية.

---

## 🎯 المميزات الرئيسية

1. **تغطية شاملة لـ 27 محافظة مصرية:**
   - من القاهرة والإسكندرية وحتى محافظات الصعيد والدلتا وسيناء والقناة.
   - البحث مقسم على مراحل (محافظة بمحافظة) لضمان عدم فقد البيانات.
2. **مصادر بيانات قانونية ومفتوحة:**
   - خوادم OpenStreetMap عبر **Overpass API** باستخدام النطاقات الجغرافية (Bounding Boxes) لسرعة ودقة الاستعلام.
   - مصادر وأدلة الأنشطة التجارية وسجلات الأعمال العامة في مصر.
3. **خوارزمية ذكية لمنع التكرار (Deduplication):**
   - مطابقة أرقام الهواتف بعد توحيد الصيغ المحلية والدولية.
   - مطابقة الأسماء بعد تطبيع الحروف العربية (إزالة التشكيل، توحيد الهمزات والألف والتاء المربوطة).
   - مطابقة التقارب الجغرافي (أقل من 60 متراً بالـ Haversine Formula).
   - دمج البيانات الناقصة والمصادر المتعددة دون تكرار المحل.
4. **توليد رسائل واتساب تسويقية مخصصة:**
   - صياغة الرسائل باللهجة المصرية الراقية والمهنية.
   - احترام نشاط المحل ودعوته لمعاينة نموذج تجريبي (Live Demo).
   - عدم إرسال أي رسائل تلقائياً؛ حفظها فقط داخل الـ JSON.
5. **مرونة واستئناف البحث (Resume Capability):**
   - حفظ مباشر بعد كل محافظة.
   - في حال إيقاف التشغيل أو انقطاع الاتصال، يستأنف النظام مباشرة من حيث توقف دون إعادة فحص المحافظات المكتملة.
   - كتابة ذرية (Atomic Write) للملفات تمنع أي تلف لملف JSON.
6. **قابلية التوسع لأي نشاط آخر:**
   - مصمم بحيث يمكن استخدامه لمحلات الهدايا أو الحلويات أو المطاعم بتغيير ملف الإعدادات `src/config/categories.js` فقط.

## 🚀 طريقة التشغيل

### تشغيل البحث وجمع البيانات:
```bash
npm run search
```

### تجربة استعراض الرسائل دون فتح المتصفح (Dry Run):
```bash
npm run send:dry
```

### إرسال الرسائل عبر واتساب (الوضع التفاعلي - ينصح به):
يفتح المتصفح لتسجيل الدخول بمسح الـ QR (مرة واحدة فقط)، ثم يستعرض كل محل ويطلب موافقتك قبل الإرسال `[y/n/q]`:
```bash
npm run send
```

### إرسال تلقائي مع تأخير أمان عشوائي وتحديد الحد الأقصى:
```bash
npm run send:auto
```

خيارات إضافية للتحكم:
```bash
# تحديد عدد المحلات المستهدفة في هذه الجلسة (افتراضياً 5 محلات للحماية)
node flower-leads/scripts/send-messages.js --limit 10

# إرسال لمحلات محافظة معينة فقط (بالعربية أو الإنجليزية)
node flower-leads/scripts/send-messages.js --governorate alexandria
node flower-leads/scripts/send-messages.js --governorate الجيزة --auto --limit 5
```

### تشغيل الاختبارات:
```bash
npm test
```

## 🔒 الأمان وشروط الاستخدام

- **عدم الإرسال التلقائي:** النظام لا يقوم بإرسال أي رسائل تلقائياً عبر واتساب؛ بل يكتفي بتجهيز الرسائل داخل ملف JSON لتتمكن من مراجعتها واختيار الوقت المناسب لإرسالها يدوياً.
- **احترام مزودي البيانات:** تم ضبط تأخير زمني وتوزيع استعلامات Overpass API على مستوى النطاقات الجغرافية مع التبديل التلقائي بين خوادم بديلة في حال الازدحام.
